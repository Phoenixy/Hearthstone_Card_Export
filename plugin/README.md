# A plugin megszűnt / The plugin is discontinued

A Hearthstone Deck Tracker 2026. november 30-tól nem tölt be pluginokat, ezért a gyűjtemény plugin helyett
a **Hearthstone Hungary alkalmazás** tölti fel a gyűjteményt (a Deck Tracker nem kell hozzá):

**https://github.com/Phoenixy/Hearthstone_Card_Export/releases/latest/download/HearthstoneHungary.zip**

Hearthstone Deck Tracker no longer loads plugins from November 30th, 2026. Use the standalone Hearthstone Hungary app (link above).
